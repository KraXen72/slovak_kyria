# Archived keymap exports

These files are retained as historical visualization exports for comparison
and recovery. They are not active firmware source and are not used by the
reproducible build.

- `visualizations/` contains old drawer exports, source layouts, and scratch
  images.
- `visualizations/legacy-layout-exports/` contains the older layer export
  inputs and images kept with those visualizations.

The current source of truth is under [`../../firmware`](../../firmware), and
the current committed visualization is under [`../../assets`](../../assets).
